# Saylens

Local voice control for the Mac: speak instead of typing (Dictate), and ask about what's on your screen (Ask). Everything runs on your own computer.

**Download:** [saylens.app](https://saylens.app) · or directly the [latest version for macOS (Apple Silicon)](https://github.com/selamiselvi/saylens-releases/releases/latest/download/Saylens.dmg)

Saylens updates itself. This repository only holds the release builds; the app's source code is not public. Saylens builds on [Handy](https://handy.computer), an open-source speech-to-text app.

**Found a bug or have an idea?** [Open an issue](https://github.com/selamiselvi/saylens-releases/issues).
